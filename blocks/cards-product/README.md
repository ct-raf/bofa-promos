# cards-product

Custom **cards** block. Purpose: Side-by-side product comparison cards for account offers.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per card, one text cell: H3 title, eyebrow, intro, CTA link, fee, Learn more link, feature paragraphs. An optional picture-only cell adds a card image.

## Supported variations

No variations.
