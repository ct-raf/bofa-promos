# cards-steps

Custom **cards** block. Purpose: Vertical list of qualification steps, each a small icon beside its copy.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per step: cell 1 icon image (or :icon:), cell 2 step copy (paragraphs, links, italic note). The icon cell may be omitted.

No variations.
