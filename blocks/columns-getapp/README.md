# columns-getapp

Custom **columns** block. Purpose: Get-the-app panel: heading, device picker and Get the app button over consent copy, beside a QR-code/phone image.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row, two cells. Text cell: H2; optional placeholder paragraph (e.g. 'Select your device'); a bulleted list of device links (iPhone, Android) whose text is the option label and href the app link (a list item without a link may also serve as the placeholder); a paragraph with the button label (e.g. bold 'Get the app'); italic consent paragraph; Terms and Conditions link. Image cell: one picture (QR code and phone). Without the button-label paragraph the device links render as a plain link list.

## Supported variations

No variations.
