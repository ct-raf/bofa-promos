# hero-offer

Custom **hero** block. Purpose: Offer masthead with left-aligned eyebrow, heading, copy and CTA over a full-width background image (often an animated GIF carrying the offer artwork on the right).

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: row 1: background image only; row 2: eyebrow paragraph, H1, intro paragraph (footnote sup allowed), CTA link. Either row may be omitted.

## Supported variations

No variations.
